Element 16 — Collection card (element-16-collection-card.html): the roster-page card (Programs / Plans / Clients) — dark surface, hue left-rail + right-glow, optional phase strip. Both are desktop/complex and live in their own files rather than this mobile frame.

The v2 rules: open by default — boxes are earned. Surfaces exist on: the hero card (1/screen), the collection card (roster pages — Programs/Plans/Clients, Element 16), the tab bar, button fills, chips, avatar. In-context sub-lists inside one item (exercises in a workout, meals in a plan) stay open rows (Element 06); roster pages of top-level entities use collection cards. Everything else sits on the background with hairlines. Where a surface exists it's the lighter #1B1E24 (or the collection card's near-black #0B0C0F). Effects budget unchanged: glow only on primary CTA, ring arcs, live status dots, hero wash — the collection card's rail/glow is ambient, not the CTA glow.

Phase-intensity scale (structure strips): a fixed training-stress ramp — light / base → moderate → hard / peak, with deload / recovery set apart. Tokens: --phase-light #22E56A · --phase-mod #FFB020 · --phase-hard #FF5A4D · --phase-deload #22D3EE. Not decorative — the bar reads as intensity at a glance.

React by number — this v2 replaces v1 as the kit.
