2. REST MODAL — ROOT CAUSE + FIX
================================================================================
Root cause (file + lines):
- InCardRestBridge in LiveWorkoutSetEntryExecutor.tsx (~old L1158–1181)
  acked `shouldOpenRestTimer` after one rAF when resolved duration was <= 0,
  starting nothing.
- Duration seed used `exercise.rest_seconds || setEntry.rest_seconds || 0`
  (handleSetComplete), while the live card *displayed* rest via
  `?? 60` (StraightSetExecutor ~L429–430). Null prescription → UI shows 1:00,
  bridge sees 0 → ack + no modal / no in-card countdown.
- handleLastSetLoggedForRest seeded next-set metadata but not restSeconds.
- Orchestrator signal itself was fine: logSet sets shouldOpenRestTimer when
  !isLastSet (useSetLoggingOrchestrator.ts ~L290–293).
- hasStarted / ?start=1 only gate mount before START — not this post-log bug.
- Removed revisit mount-time completion effect was auto-advance only; not the
  first-set rest trigger.

Fix:
1. resolveRestSeconds() aligned with card display (`?? 60` when both null).
2. Seed restStartRef *before* orchestrator.logSet when !isLastSet.
3. handleLastSetLoggedForRest / handleSetComplete use the same resolver.
4. InCardRestBridge: never ack on 0s immediately; retry ~600ms, then ack only
   if still zero (true no-rest).
