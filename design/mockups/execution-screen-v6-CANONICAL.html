Client execution screen — v6 canonical. One card system, three layouts, fixed property slots. Colours = per-group hue on rail + badge; neutral borders. Green = mark done, blue = go. Numbers read reps × weight everywhere. Effort is the intensity-coloured word + RPE. Slots never move; the card just grows taller when a property is present.
Layout A · Solo (straight · drop · cluster · rest-pause · timed · distance) — Layout B · Grouped (superset · giant) — Layout C · Protocol (AMRAP · EMOM · Tabata · for-time). Techniques and protocols are the same card: only the technique block, the unit label, the clock, and the log control change.
