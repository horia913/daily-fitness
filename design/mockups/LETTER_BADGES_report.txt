2. Letter derivation
- Source: **group index in the workout** (0 → A, 1 → B, …) via
  `groupIndexToLetter` / `formatGroupedExerciseBadge` in
  `groupLetterBadges.ts`.
- Exercise order within the group: `exercise_order` when set, else 1-based
  index → `A1`, `B2`, etc.
- DB `exercise_letter` exists on the type but is typically a within-block
  slot (or null), not a workout-position letter — **not used** as the
  prefix, so two supersets don’t both become A1/A2.

- Was: `return \`A${exerciseOrder ?? index + 1}\`` in Superset, Giant, Amrap,
  plus helpers / round summaries.
- Now: prefix = `groupIndexToLetter(currentSetEntryIndex)` /
  list `index` for ExecGroupList.

  range isn’t duplicated beside the badge.
