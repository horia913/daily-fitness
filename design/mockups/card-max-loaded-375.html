The good news: width holds — every row (2-col primary, 3-col stat strip, technique, note, 2-field log) fits 375px; only height grows, and the page scrolls.

The slot schema, fully populated: name + swap · Target (+ load %) | Effort · Rest·Tempo·Last · Technique · Note · Log · set rows. Every configurable property has one fixed home.

Two that aren't shown in the app today — your call:
· Load % — shown here as "· 75%" on the target. Show it to the client, or is the absolute weight enough?
· Coach note — client-facing cue slot. Do coach notes belong on the client card, or are they coach-only? If client-facing, it needs this slot.

And the real density ceiling: a giant set repeats the per-exercise block ×3 in one card. That's the tallest thing the screen can produce — worth deciding whether grouped exercises show the full per-exercise property set or a trimmed one, so three stacked don't become a wall.
