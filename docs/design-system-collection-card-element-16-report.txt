## 3. Component API, location, CSS convention

**Location:** `src/components/ui/CollectionCard.tsx` + `src/components/ui/collectionCard.module.css`

**Convention:** Co-located CSS module (same pattern as `coachNutritionWorkspace.module.css`, coach station modules). UI primitives in `components/ui/` use global `fc-*` classes when token-only; new governed element uses a module because Element 16 has a large, self-contained ruleset matching the mockup HTML/CSS — mirrors coach workspace components rather than polluting `ui-system.css` with 200+ lines of card anatomy.

### Exports

| Export | Role |
|--------|------|
| `CollectionCard` | Main card shell |
| `CollectionCardStack` | 12px vertical gap wrapper (`.stack`) |
| `CollectionCardMetaChip` | Level chip in meta line |
| `CollectionCardMetaSep` | `·` separator |
| `CollectionCardMetaValue` | Emphasized mono value |
| `CollectionCardMetaText` | Plain meta span |
| `CollectionCardAssignedStat` | Programs-style right stat (count + optional avatars) |
| `CollectionCardIconAction` | Ghost icon button (default / danger) |
| `COLLECTION_HUES` | `{ a, b, c, d }` → `var(--fc-group-*)` |

### `CollectionCard` props

| Prop | Type | Required | Notes |
|------|------|----------|-------|
| `hue` | `string` | yes | CSS color for `--collection-hue` (rail + glow + stat accent) |
| `name` | `string` | yes | Archivo title |
| `status` | `'active' \| 'inactive'` | yes | Dims card, gray rail, suppresses glow when inactive |
| `statusLabel` | `string` | no | Default "Active" / "Inactive" |
| `meta` | `ReactNode` | yes | Meta line slot |
| `structure` | `CollectionCardStructureSegment[]` | no | Phase strip — omit for Clients etc. |
| `rightStat` | `ReactNode` | no | Score ring, assigned count, etc. |
| `actions` | `ReactNode` | no | Icon button row |
| `className` | `string` | no | |
| `onClick` | `() => void` | no | Makes root a `<button>` |

### `CollectionCardStructureSegment`

| Field | Type | Notes |
|-------|------|-------|
| `label` | `string` | Phase name under bar |
| `duration` | `string` | e.g. "4 weeks" |
| `flex` | `number` | Segment width proportion |
| `phase` | `'light' \| 'moderate' \| 'hard' \| 'deload'` | Maps to `--phase-*` via CSS class |
