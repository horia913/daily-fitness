## 2. Draft + commit design

### Mirror of ProgramDraftContext
| Concern | Program station | Meal plan draft |
|--------|-----------------|-----------------|
| State | `baseline` + `workingCopy` | Same |
| Dirty | structural/json compare | `mealPlanDraftsEqual` on normalized tree |
| localStorage | 500ms debounce | Same (`mealPlanDraftStorage`) |
| Resume prompt | `resumePrompt` dialog | `MealPlanDraftResumeDialog` |
| Save states | idle/dirty/saving/saved/error | Same |
| Nav guard | beforeunload + LeaveConfirmDialog | Same (back link to nutrition) |
| DB writes | explicit `commit()` | `commitMealPlanTree()` |

### Commit operation order
1. **Delete** meals present in baseline but absent from workingCopy (real ids only)
2. For each meal in workingCopy **by array position** (`order_index = index`):
   - **New meal** (`temp-*`) → `createMeal` (meal + default option) → backfill meal id + first option id
   - **Existing meal** → `updateMeal` if name/type/order changed
   - **Delete** removed options (real ids)
   - For each option by position:
     - **New option** → `createMealOption` → backfill option id → `updateMealOption` order if needed
     - **Existing option** → `updateMealOption` name/order
     - **Delete** removed foods
     - **New food** → `addFoodToOption` → backfill food item id
     - **Changed food** → `updateFoodInOption` qty/unit

### Temp id → real id backfill
- Temp prefix: `temp-{uuid}`
- During commit, `draft` is a **clone** of workingCopy; successful creates **mutate ids in place** on `draft`
- On partial failure: `result.state` returned with backfilled ids; context calls `setWorkingCopyState(result.state)` — retry only creates rows still carrying `temp-*` ids

### Retry safety
- Backfilled rows become updates/deletes on retry (idempotent)
- Only remaining `temp-*` rows trigger inserts
- Failed commit keeps `saveState: error` and workingCopy dirty

### order_index
Written from **array position** on create (`createMeal`) and update (`updateMeal` / `updateMealOption`) for every commit.

### New
```ts
static async createMeal(
  mealPlanId: string,
  data: { name: string; meal_type: string; order_index: number },
): Promise<{
  meal: { id: string; name: string; meal_type: string; order_index: number };
  defaultOption: MealOption;
}>

static async updateMeal(
  mealId: string,
  updates: Partial<{ name: string; meal_type: string; order_index: number }>,
): Promise<void>

static async deleteMeal(mealId: string): Promise<boolean>
```

`createMeal` inserts `meals` row **and** first `meal_options` row (`Option 1`, `order_index: 0`) — options-first.
