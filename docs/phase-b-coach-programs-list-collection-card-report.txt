## 2. API extension

### Additive fields (per program in `programs[]`)

| Field | Source |
|-------|--------|
| `blocks` | `getMasterProgramBlocksBatch()` — `{ name, phase_label, duration_weeks, block_order }[]` ordered by `block_order` |
| `assignedPreview` | `{ count, initials[] }` — count matches existing tally; up to 3 initials from profiles |
| `periodization_style` | Already in `select('*')` on `workout_programs` — passes through unchanged |

### New helper

**`getMasterProgramBlocksBatch`** (`src/lib/programs/masterProgramBlocksBatch.ts`)
- Single query: `training_blocks` WHERE `program_id IN (…)` SELECT name, phase_label, duration_weeks, block_order
- Returns `Map<programId, MasterProgramBlockRow[]>`
- **Does not modify** `getMasterProgramTotalWeeksBatch`

### Assignments enrichment

- Was: `select('program_id')` → count only
- Now: `select('program_id, client_id, created_at')` ordered desc
- Count logic **unchanged** (increment per row)
- Preview: first 3 unique `client_id` per program → batch `profiles` query → initials via `clientInitialsFromProfile`

### Preserved behavior

- Filter: `filter=active|all`, default active
- Ordering: `created_at desc`
- `is_active` filter when active
- `totalWeeks` via `getMasterProgramTotalWeeksBatch` (unchanged)
- `target_audience` default
- Top-level `assignmentCountByProgram` object (unchanged shape)

## 3. Phase mapper + structure strip

**File:** `src/lib/programs/mapProgramBlockPhaseSegments.ts`

**Exports:**
- `mapProgramBlocksToPhaseSegments(blocks)` → `{ label, weeks, level }[]`
- `mapProgramBlocksToStructureSegments(blocks)` → `CollectionCardStructureSegment[]`

**Rules (priority):**
1. Deload override — recovery keywords in `phase_label` or `name` → `deload`
2. Keyword by meaning — light / mod / hard dictionaries
3. Order-based ramp on non-deload blocks — 1→mod, 2→light+mod, 3→light+mod+hard, 4+→distributed light→mod→hard (last→hard)

**Strip rendering:** `structure` prop passed **only when `blocks.length > 1`**. Single-block programs omit the strip.

**Label:** `phase_label` if non-empty, else `name`. Duration sublabel: `{n} week(s)`. Width ∝ `duration_weeks`.

## 4. Card prop mapping

| Prop | Source |
|------|--------|
| `hue` | `programCollectionHue(program.id)` — stable hash over `COLLECTION_HUES` |
| `name` | `program.name` |
| `status` | `is_active` → active/inactive |
| `meta` | **Real fields only:** difficulty chip · `{totalWeeks} wks` · periodization label (if `periodization_style` set). **No** Fixed / days-per-week (not on `workout_programs`) |
| `structure` | Mapper output when `blocks.length > 1` |
| `rightStat` | `CollectionCardAssignedStat` — count from `assignedPreview.count`; avatars from initials + `avatarHueByIndex` |
| `actions` | View → `/coach/programs/[id]`, Assign → `openAssignModal`, Edit → `/coach/programs/[id]/edit`, Delete → delete modal |
