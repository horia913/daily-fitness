INSTANCE BRANCH — OWNERSHIP RESOLUTION
================================================================================

If row exists:
  program_assignments.eq('id', program_assignment_id)
                    .eq('client_id', auth.uid())
  If no match → throw "Workout not found" (no legacy fallback noise).

If owned:
  get_instance_workout_canvas via loadInstanceWorkoutForCanvas (existing RPC).
  Content → mapInstanceCanvasToSetEntries (no get_workout_blocks, no
  workout_templates / workout_set_entries reads).

If id is not an instance row → fall through to workout_assignments id lookup,
then workout_template_id fallback (standalone assignments unchanged).
