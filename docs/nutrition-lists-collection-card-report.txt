## 2. `assignedPreview` extension + stats preservation

**File:** `fetchNutritionWorkspaceData.ts`

**Change (additive only):**
- `meal_plan_assignments` query extended from `select("meal_plan_id")` to `select("meal_plan_id, client_id")`.
- Per plan: up to 3 unique `client_id`s collected (same dedupe/cap pattern as Programs API).
- One batched `profiles` fetch for all preview client ids.
- Each plan row now includes:

```ts
assignedPreview: {
  count: number;      // mirrors usage_count
  initials: string[]; // up to 3, via clientInitialsFromProfile
}
```

**Preserved unchanged:**
- `meal_count` — still aggregated from `meals` table.
- `usage_count` — still total assignment row count (all assignments, not filtered by `is_active`).
- `MealPlanService.getMealPlans(coachId)` base fields untouched.
- `fetchNutritionWorkspaceMeta` untouched.
