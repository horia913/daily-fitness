## 2. API extension + behavior preservation

### `mealPlanName: string | null`

- Batched query: `meal_plan_assignments` (`is_active = true`, newest per client) → `meal_plans.name`
- One name per client; `null` when no active assignment

### `scoreIsStale: boolean`

- Computed in route via `computeScoreIsStale(athleteScore, metrics.lastActive)`:
  - `true` when `athleteScore` exists **and** `calculated_at` date (YYYY-MM-DD) **<** `lastActive`
  - `false` when `lastActive` is null (per spec)
  - `false` when no score row
- `calculated_at` added to `fetchCoachAthleteScoreSummariesByClientIds` return value (read-only pass-through from `athlete_scores`; **no recalculation**)

### Preserved unchanged

- `getClientMetrics`, `fetchCoachClientListTrainingPayload`, `computeClientTrainingStatus`
- All existing client fields and join behavior
- `calculateAthleteScore` / cron — **not touched**

## 3. List-card slot mapping

| Slot | Implementation |
|------|----------------|
| **avatar** | `avatar_url` image or initials (`clientInitialsFromName`) in `CollectionCard` `avatar` slot |
| `hue` | `coachClientAttentionHue(trainingStatus)`: on_track → `--fc-status-success` · behind → warning · missed_week → error · paused/no_program → subtle. Roster `inactive` → muted hue |
| `name` | `client.name` |
| `status` | Training pill via `statusLabel` + `statusTone`. Roster **inactive** → `cardStatus: inactive` + “Inactive”. **pending** → “Pending” (muted tone). Else training labels (On track / Behind / Missed week / Paused / No program) |
| `meta` | Program name (or “No program”) · Week X of Y when both set · Active {relative} · Check-in {relative} · `mealPlanName` when present. Page `formatMetaPart` / `formatRelativeTime` reused |
| `structure` | **Omitted** |
| `rightStat` | `AthleteScoreRing` when `athleteScore != null && !scoreIsStale`; else muted **—** + sublabel **no score**. Never shows stale or fake 0 ring |
| `actions` | `CollectionCardIconAction` View → `/coach/clients/[id]` · `CoachClientProgramPauseMenu` (unchanged) |

Header, search, roster pills, quick filters, sort menu, list/grid toggle, Add + Bell — **unchanged** in `page.tsx`.
