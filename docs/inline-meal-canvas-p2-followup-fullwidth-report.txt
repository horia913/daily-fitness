## 2. Station width finding

**Route:** `/coach/programs/[id]/edit` → `ProgramStationShell`

The program station nominally uses `CoachPageShell widthVariant="data-7xl"` (1280px cap), but the editing canvas is **not** capped in practice. `ProgramStationShell` applies `stationEditor.module.css` class `.shell` on the shell:

```css
.shell {
  max-width: none !important;
  width: 100%;
  padding-left: 0 !important;
  padding-right: 0 !important;
}
```

Horizontal gutters are applied one level inward via `.contained`:

```css
.contained {
  width: 100%;
  max-width: none;
  padding-inline: var(--se-gutter);  /* --se-gutter: 22px */
}
```

**Conclusion:** The station is **effectively full-width** — no max-width cap on the editing canvas, symmetric horizontal gutters (22px) on inner content. It achieves this via a **local CSS override** on top of `data-7xl`, not via a dedicated `CoachPageShell` variant.
