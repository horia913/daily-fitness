Principles applied

  1. Thin periodization chevron ribbon (#1). Each phase is a clip-path arrow that points into the next (base ▸ build ▸ peak ▸ deload). Negative margin nests tip into notch — continuous flowing ribbon, no gaps. Filled with --phase-light / --phase-mod / --phase-hard / --phase-deload. Active: brightness + white drop-shadow edge that follows the chevron.
  2. Density / text-forward. Tighter gaps (3–10px), smaller mono labels, more weeks visible at once, volume as a compact side rail, exercise rows with mono prescriptions. White/bright type carries hierarchy.
  3. Color = functional. Appears for: phase intensity (band + week ticks), volume status, selected week, letter badges, Save CTA. No atmospheric blobs, no cyan volume chrome, no full-card teal blaze.
  4. Organized columns. Hairline dark cards, clear Mon + day name + meta, exercise list with tiny badges — accent, not headline.
Not muted: phase greens / ambers / reds / cyan stay fully saturated inside the thin band; volume status stays vivid; Save keeps blue glow. Energy is concentrated into meaning — thin and loud where it earns it, quiet everywhere else.
