What changed & why

  1. Block 1 bar — full blaze → rail + wash + text. Current: solid glossy #2EF2C6 fill with near-black label (label lost in brightness). After: same saturated teal as a 5px glowing rail + soft wash (coach status-row pattern from v5), plus a small solid teal chip. The name “Block 1” is large white display type — it reads. Saturation stays; it no longer fills half the viewport as a light source.
  2. Fewer simultaneous cyans. Before: phase bar + active week + volume chrome (#19e3c4) + day-name teal + letter badges all shout at once. After: teal is reserved for block identity, selected week ring, and letter badges. Day names, volume total, exercise names go to primary text white.
  3. Volume numbers lead; chrome steps back. Drop the cyan gradient header / cyan total. Keep status colors on per-muscle counts (green OK / amber low) — those earn attention. The “48” is a display number in white, not another teal beacon.
  4. Day columns: accent supports, names lead. Softer left wash; day title in white (not teal). Letter chips keep saturated teal — small, high-signal accents, not competing headlines.
  5. “2 dull circles” identified & removed in After. They are not status indicators — atmospheric radials on stationEditor.module.css .root::before (left teal ~4%, right orange ~3.5%). Visual noise that adds cool/warm blobs behind the UI. After panel drops them so the workspace stays immersive without fake “orbs.”
  6. Save CTA unchanged — glossy blue with glow. Energy lives on the action that commits work, not on every chrome surface.
Not muted: teal rail still glows, active week still rings teal, badges stay aqua, Save stays electric blue, volume status stays green/amber. Hierarchy changed — saturation did not leave the building.
