## 3. How the layout fills (rebalance)

| Region | Full-width behavior |
|--------|---------------------|
| **Header** | Full width within gutters; eyebrow + greeting + ghost CTA unchanged |
| **Stat strip** | 6-column grid @≥1024px — **spreads across full canvas** (intentional open strip) |
| **Queue grid (cols 1–2)** | `minmax(0, 1fr)` / `minmax(0, 1.45fr)` — **absorb extra width** on wide screens |
| **Today / Quick actions (col 3)** | **Capped** `minmax(260px, 20rem)` @1024, `minmax(280px, 22rem)` @1280 — prevents ghost buttons and Today rows from stretching awkwardly wide |
| **Gap @1280+** | `clamp(30px, 2.5vw, 48px)` — uses horizontal space between columns without over-spacing rows |

Multi-column structure preserved: Need attention / Behind / Flagged | Inactive check-ins | Today + Quick actions.

**Eyebrow judgment:** On ultrawide monitors with sparse queue data, columns 1–2 can feel horizontally roomy (long hairline rows, few items) — same density trade-off as Programs cards on a wide roster. Column 3 cap avoids the worst stretch. Stat strip six-across is the intended “dashboard at a glance” scan line; no cap added there.
