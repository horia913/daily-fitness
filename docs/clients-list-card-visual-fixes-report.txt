## 4. Fix summaries

### Ring
- New `ClientListScoreRing` in `CoachClientListCard.tsx` (not the grid chip).
- 46px ring, 4px stroke, tier-colored arc + **number centered inside** (`position: absolute; inset: 0`).

### Stale / null
- `CoachClientListScoreStat`: ring only when `athleteScore != null && !scoreIsStale`.
- Otherwise muted **`—`** + **`no score`** sublabel. No stale warning, no date, no zero ring.

### Density
- `density="compact"` on client list card: reduced padding, `align-items: flex-start`, side column no longer `space-between`, body gap 8px, name 18px.

### Meta phrasing
- `lastActive` null → **"No recent activity"** (not "Active Never trained").
- `lastCheckinDate` null → check-in segment **omitted**.
